# MindPal Handover Document
## Introduction
MindPal is a mental wellness application designed to provide users with a personalized and interactive experience for managing their mental health. This handover document outlines the key features, technical details, and instructions for running the application.

## Features
* User authentication and authorization using Firebase
* Note-taking feature with CRUD operations
* Tagging system for organizing notes
* User profile management with profile picture and bio editing
* Modern design and animations for an enhanced user experience

## Technical Details
* Frontend: React, Redux, and Firebase
* Backend: Firebase Firestore and Firebase Authentication
* Database: Firebase Firestore

## Running the Application
1. Clone the repository: `git clone https://github.com/username/mindpal.git`
2. Install dependencies: `npm install`
3. Start the application: `npm start`

## Testing the Application
1. Run unit tests: `npm test`
2. Run integration tests: `npm test --integration`
